# Third-party foundations

This project does not claim authorship of its CAD kernel or modeling framework.

| Component | Purpose | Upstream license/source |
| --- | --- | --- |
| build123d | Python modeling framework for the first engineering experiment | [Apache-2.0](https://github.com/gumyr/build123d) |
| Open CASCADE Technology | Boundary-representation geometry and CAD interchange, accessed through build123d/OCP | [LGPL-2.1 with additional exception](https://github.com/Open-Cascade-SAS/OCCT) |
| three.js | CAD-derived mesh rendering and orbit controls | [MIT](https://github.com/mrdoob/three.js) |
| Vite | Build tooling for locally bundled browser assets | [MIT](https://github.com/vitejs/vite) |
| ezdxf | Validated DXF output for the implemented 2D entity subset | [MIT](https://github.com/mozman/ezdxf) |

The project MIT license applies to our original code. It does not relicense these
dependencies. Installed packages retain upstream license files. Distributing a packaged application will require preserving upstream
notices and satisfying the licenses of the actual included dependencies.

No proprietary product code, brand assets, templates, or sample projects are copied.
Reference product names identify compatibility and workflow research, not affiliation.
